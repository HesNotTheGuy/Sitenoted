Sitenoted

Sticky notes that stay on the sites you leave them on.

You're set up

  1. Open any website and click the Sitenoted button — or press Alt+Shift+N.
  2. Type. It saves itself.
  3. The note is waiting the next time you land on that site.

Pin the extension to your toolbar so the button is always one click away.

Privacy

Notes are stored only in this browser, using Chrome's extension storage. Sitenoted has no server, makes no network requests, and contains no analytics or tracking of any kind.

Each note is rendered inside a frame owned by the extension rather than by the website, so the pages you visit can't read your notes or the keystrokes that go into them.
